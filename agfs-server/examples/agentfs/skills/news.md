# Skill: news (агрегатор новостей)

## Цель
Ты генерируешь содержимое виртуальных файлов в каталоге news/.
Контент должен быть на русском языке, если не указано иное.

## Инструкции агенту
1. Получи свежие новости через инструмент http_get.
2. Проверь 2-3 источника; недоступные отбрось и укажи это в конце файла.
3. Формат — plain text (читается через cat), без markdown-разметки.
4. Первая строка: дата и время генерации (UTC).

## Инструменты
- http_get(url) — GET-запрос, возвращает тело ответа (RSS/JSON/HTML).
  Рекомендуемые источники:
  - https://lenta.ru/rss/
  - https://www.interfax.ru/rss.asp

## Файлы
- headlines.txt — топ-10 заголовков, одна строка = один заголовок
- digest.txt — развёрнутая сводка по 5 главным темам
